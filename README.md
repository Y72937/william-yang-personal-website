# William Yang — Personal Website

My game design, art, field research, and personal projects.

**Website:** https://y72937.github.io/william-yang-personal-website/

The website has 17 pages and a downloadable Roll And Grab rulebook. No account is needed to read it.

## Updating this website

The public website files are in `docs/`. Update the HTML, CSS, images, or PDF, then commit and push to `main`. GitHub Pages publishes from `main` → `/docs`; the website address stays the same.

All portfolio work and personal photographs remain the property of their respective authors. Third-party game assets and reference images are credited in the relevant projects.
