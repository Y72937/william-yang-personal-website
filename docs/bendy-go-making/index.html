02 / 02 · Making the prototype

Movement as an Input

I used flex sensors and Arduino to collect movement data, then connected that input to a game through Python. Bending becomes a way to control what happens on screen.

Wear. Move. Play.

I worked on the wearable prototype, the game interface, and the connection between them. The project let me bring physical movement and a digital game into the same interaction.

Building the game world

I also made the game environment in Blender and worked through the visual design alongside the physical prototype.

My prototype uses Arduino, flex sensors, Python, and a screen-based game. Development included AI-assisted coding.
